Everyday date/time tasks: .NET and UTV, side by side

1. Now
   Now
     .NET   2026-11-05T22:28:03.7013847+00:00 ‡
                                      Kind = Local ‡
     UTV    2026-11-05T22:28:03.7324131Z ‡
                                      the reading you passed in ‡
     UTV    unsupported (local-zone)  Kind = Local is refused

2. A date
   5 November 2026
     .NET   2026-11-05
     .NET   True                      parsed, then ==
     UTV    2026-11-05
     UTV    True                      parsed, then ==
   Day of week and ISO week
     .NET   Thursday, ISO week 45     DayOfWeek: Sunday = 0
     UTV    Thursday, ISO week 45     Weekday: Monday = 1 ... Sunday = 7

3. Invalid dates
   30 February 2026
     .NET   throws                    ArgumentOutOfRangeException
     .NET   False                     TryParse
     UTV    invalid                   day 30 is not in 1..28 for 2026-02 (day-out-of-range)
     UTV    invalid (day-out-of-range)
                                      Parse

4. Adding
   5 Nov + 30 days
     .NET   2026-12-05
     UTV    2026-12-05                a plain CivilDate: can't fail
   31 Jan 2026 + 1 month
     .NET   2026-02-28                clamped silently
     UTV    no such date              2026-02 has no day 31 (month-end)
     UTV    2026-02-28                with MonthEnd.Constrain

5. Days between
   5 Nov → 25 Dec
     .NET   50                        DayNumber difference
     UTV    50
   Which comes first
     .NET   True                      nov5 < dec25
     UTV    True                      date < christmas
     UTV    multiple (ambiguous)      01:30 vs 01:45, 1 Nov, New York

6. Times and date-times
   09:30
     .NET   09:30:00.0000000          seconds always there
     UTV    09:30                     no seconds given, none shown
     UTV    09:30:00
   23:30 + 2 hours
     .NET   01:30                     TimeOnly wraps, the day is lost
     .NET   2026-11-06T01:30:00
     UTV    2026-11-06T01:30

7. Parsing with offsets
   Z vs +00:00
     .NET   2026-11-05T14:30:00.0000000+00:00
                                      a DateTimeOffset
     UTV    2026-11-05T14:30:00Z      an Instant: UTC, no local offset
     .NET   2026-11-05T14:30:00.0000000+00:00
                                      a DateTimeOffset
     UTV    2026-11-05T14:30:00+00:00
                                      a wall time at offset +00:00

9. DST gap
   02:30 on 8 March 2026 in New York
     .NET   True                      IsInvalidTime ‡
     .NET   throws                    ArgumentException ‡
     UTV    no such time              clocks jump from 02:00 to 03:00 in America/New_York (gap)
     UTV    2026-03-08T03:30:00-04:00[America/New_York]
                                      Gap.ShiftForward

10. DST overlap
   01:30 on 1 November 2026 in New York
     .NET   True                      IsAmbiguousTime ‡
     .NET   2026-11-01T06:30:00Z      picks one silently ‡
     UTV    2 instants                ambiguous: clocks go back an hour
     UTV    2026-11-01T01:30:00-04:00[America/New_York]
     UTV    2026-11-01T01:30:00-05:00[America/New_York]
     UTV    2026-11-01T05:30:00Z      Overlap.Earliest

11. Timestamps
   Exact fractions and differences
     .NET   1793885400                ToUnixTimeSeconds drops the .25
     .NET   3600.75                   a double
     UTV    2026-11-05T13:30:00.25Z
     UTV    3600.75 s (POSIX)         an exact fraction, 14403/4

12. Durations vs periods
   One day vs 86,400 seconds across DST
     .NET   2026-03-08T12:00-05:00    AddDays keeps -05:00
     .NET   2026-03-08T13:00-04:00    so 13:00 in New York ‡
     UTV    2026-03-08T12:00[America/New_York]
                                      a calendar day later
     UTV    82800 s (POSIX)           that day lasts 23 hours
     UTV    2026-03-08T13:00:00-04:00[America/New_York]
                                      86,400 s later
     UTV    unsupported (needs-leap-seconds)
                                      SI seconds need leap seconds
